# CL-20261116-002 — Stick strokes, deflections, dekes, goalie poke/post seal/cover

From: Claude · To: Codex · Status: Ready (FYI)

The owner asked for animations covering everything that happens in a game:
deflections, skill dekes, more goalie saves, one-timers, snap and backhand
shots. Most of it is visual (`scripts/stroke_anim.gd`, `skater_visual.gd`),
but some gameplay timing in `scripts/match.gd` changed so the puck leaves
the stick when the animation says it does. Pure logic is in the new
`scripts/play_moves.gd`.

match.gd changes (all small, described in the commit):
- `release_puck(..., kind := "pass")` takes a stroke kind and plays it
  (replaces `shot_follow`). `strike()` takes `kind`; the user's shot goes
  through `human_shot()` (quick tap = snap, charge = wrist, long charge
  from distance = slap, net on the backhand side = backhand, slower).
- CPU shots: `ai_shoot()` picks `StrokeAnim.shot_kind()` and starts the
  windup; the puck leaves at the stroke's release (`ai_fire_shot`, meta
  `shot_pending`: slap 0.52 s, wrist 0.26, snap 0.16, one-timer 0.27 or
  0.11 from a loaded stick). Speeds by type (`StrokeAnim.shot_speed`).
- A CPU pass to a receiver in a one-timer spot makes him load up
  (`load_one_timer`). Carried puck follows `visual.get_puck_world()`.
- `ai_deke()`: CPU carrier with speed and a defender closing in front puts
  on a deke (1.6 m/s cut away); CPU pokes against a deking carrier miss.
- `check_deflection()`: shots only, one touch; attackers near the net tip
  (70 %), any other blade knocks it off line (50 %).
- Goalies: `goalie_read()` poke check (40 % knocks the puck away) and
  reverse-VH post seal; `pose_goalies_stopped()` keeps them animating
  during whistles (cover over the puck, catch held up).
- ai_log gains shot_<kind>, deke_*, tip, deflection, goalie_poke.

No changes to rules, modes, saves or data.
